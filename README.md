# 🐋 大肥鱼 AI 虚拟互动直播系统 (DaFeiYu Live)

> 抖音爆款“高能二次元蓝鲸娘 + 怀抱傲娇大肥鱼”无人无人值守/半自动虚拟主播系统。
> 原生集成 **3D WebGL 骨骼动力学真·跳舞引擎**、**Live2D 拟真表情**、**小肥鱼养成进化**、**智能点歌压音** 与 **全自动化弹幕实时互动**。

---

## 🌟 核心特色与技术亮点

### 1. 💃 3D WebGL 原生骨骼动力学跳舞引擎
- **真·全身 3D 骨骼驱动**：不同于常规 2D 图片抖动，采用 Three.js + GLTF Humanoid 骨骼绑定体系，包含全身 53 个关键运动节点（脊椎、胸部、肩膀、手肘、腕关节、髋骨、膝盖、脚踝）。
- **极乐净土与热舞模式**：观众公屏发送 `跳舞`、`极乐净土` 或点击控制栏，主播立即启动全身流畅动作起舞，伴随 3D 环绕霓虹舞台射灯与小肥鱼伴舞。
- **自然灵动待机交互**：
  - **3D 视线与头部鼠标追随**：平滑插值追踪观众鼠标空间坐标，头部与颈部自然转向跟随。
  - **动态微呼吸沉浮**：自然下垂的手臂与身姿随水下多频呼吸波浪起伏。

### 2. 🐟 标志性萌系小肥鱼吉祥物与进化系统
- 具有呼吸、浮动游曳与弹幕说话节奏律动。
- **投喂养成与体重增长**：观众发送 `投喂`、送出小鱼干礼物，大肥鱼体重实时增长并触发全屏升级特效。

### 3. 🎵 智能 Hi-Fi 点歌台与压音闪避 (Audio Ducking)
- **本地优先 + 在线实时检索**：优先秒播本地 `music/` 目录中的歌曲，无本地曲目时自动无缝衔接在线音乐。
- **智能压音闪避**：当主播开口互动说话时，背景音乐音量自动平滑压低至 20%，语音结束后自动恢复，确保人声清晰动听。
- **听前奏猜歌盲盒大挑战**：公屏发送 `猜歌` 即可开启 20 秒经典金曲前奏竞猜。

### 4. ⚡ 抖音全场景弹幕自动接管
- **进房欢迎**：0.8 秒极速迎客，东北大碴子幽默傲娇人设。
- **关注感谢 / 粉丝团庆贺**：捕捉粉丝动作，专属语音鸣谢。
- **礼物轰炸**：全屏小鱼干金币雨 + 专属激萌谢礼。
- **防冷场自动插播**：超过 20 秒无人发言自动随机暖场。

### 5. 🛡️ 防录播判定与纯净推流
- 内置实时动态毫秒级时钟与 REC 呼吸标识，彻底规避平台录播检测。
- 键盘一键按 **`H`** 开启纯净推流模式，自动隐藏所有操作按钮，直接供抖音直播伴侣采集。

## 🚀 快速启动

### 1. 环境准备
- Python 3.10+
- 推荐使用现代浏览器（Edge / Chrome）

### 2. 依赖安装
```bash
pip install aiohttp edge-tts openai websockets
```

### 3. 配置
复制 `config.example.json` 为 `config.json`，填入你的大模型 API 密钥（兼容 DeepSeek / OpenAI 接口）：
```json
{
  "api_key": "YOUR_API_KEY",
  "base_url": "https://api.deepseek.com",
  "model": "deepseek-chat",
  "voice": "zh-CN-liaoning-XiaobeiNeural",
  "port": 8765
}
```

### 4. 一键启动
双击运行目录下的：
```bat
start.bat
```
浏览器打开 `http://localhost:8765` 即可在抖音直播伴侣中通过“添加窗口 / 浏览器图层”采集推流！

## 📡 抖音直播间弹幕接入方式

### 方式 A：浏览器控制台直连（零下载软件）
1. 在浏览器打开你的抖音网页直播间（`https://live.douyin.com/你的房间号`）；
2. 键盘按 **F12** 打开控制台 (Console)；
3. 将项目目录中的 `douyin_web_relay.js` 全选复制粘贴入控制台回车，弹幕即刻实时打通！

### 方式 B：配合开源抓取工具（如 WssBarrageServer / 弹幕库）
系统默认自动监听本机 `ws://127.0.0.1:8888` 弹幕转发接口，开启软件即可自动接管。
